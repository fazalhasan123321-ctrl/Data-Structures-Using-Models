# Data Structures Using Python

## Overview
This repository contains implementations of fundamental Data Structures using Python. The programs demonstrate how different data structures work and how they can be used to solve real-world problems efficiently.

## Topics Covered

### Linear Data Structures
- Arrays
- Lists
- Stacks
- Queues
- Circular Queue
- Priority Queue

### Linked Lists
- Singly Linked List
- Doubly Linked List
- Circular Linked List

### Non-Linear Data Structures
- Trees
- Binary Trees
- Binary Search Trees (BST)
- Graphs
- Heaps

### Hashing
- Hash Tables
- Dictionaries

### Searching Algorithms
- Linear Search
- Binary Search

### Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Technologies Used
- Python 3
- VS Code / PyCharm
